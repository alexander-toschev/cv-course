# Чеклист лекции / Lecture release checklist

Для каждой новой или содержательно переработанной лекции обязательны все четыре элемента на двух языках. / Every new or substantively revised lecture requires all four components in both languages.

- [ ] Презентация RU и EN / Slides RU and EN — Google Drive.
- [ ] Видеолекция со слайдами и озвучкой RU и EN / Slide video with narration RU and EN — Google Drive.
- [ ] Практика RU и EN / Practice RU and EN — папка лекции / lecture folder, GitHub.
- [ ] Отдельное ДЗ RU и EN / Separate homework RU and EN — та же папка / same folder, GitHub.
- [ ] Практика и ДЗ используют известные реальные датасеты, указывают источник, условия, смысл наблюдения, признаки, цель и ограничения разбиения. / Practice and homework use known real datasets with sources, terms, observation meaning, features, targets and split restrictions.
- [ ] Colab/CPU-запуск воспроизводим; тесты ДЗ проверяют решения; вывод содержит ID, имя, группу и исходный балл без локального штрафа. / Colab/CPU execution is reproducible; tests validate solutions and output assignment ID, identity and raw score without a local-time penalty.
- [ ] Срок берётся из матрицы по группам, штраф — по подтверждённому времени сдачи. / Use group deadlines and verified submission timestamps for lateness.
- [ ] README содержит рабочие ссылки на все элементы. / README links all deliverables.

Двуязычный ноутбук с полными инструкциями RU/EN подходит для практики и ДЗ. Презентации и видео выпускаются отдельными RU/EN-файлами. / A notebook containing full RU/EN instructions is acceptable for practice and homework. Slides and videos use separate language files.
